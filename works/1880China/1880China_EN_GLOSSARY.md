## 4. Style rules

1. **Literal translation.** No summarizing, no merging, no reordering. Every table row, every
   footnote, every caveat survives.
2. **All numbers verbatim — including the currency symbol.** 1880's in-game currency is **¥** in the
   English rulebook as well, so **keep `¥`; do NOT convert to `$`** (this differs from the 1846 report).
3. **Markdown structure preserved** — same heading levels, same table shapes, same emphasis, same code blocks.
4. **Chinese book quotes 「」→ English double quotes.** Full-width colon `：` → `: `.
   `——`（中文双破折号）→ `—`.
5. **`｜`（全角竖线）用作单元格内容分隔符时必须转义为 `\|`**，否则撑破表格。
6. **Player handles**: `玩家X` → `PlayerX` with the **same number**; TOP-group real names copied unchanged;
   company abbreviations (HKR, BCR, JHA…) **not translated**.
7. Section labels `§0`–`§10` keep their numbering; `〇` → `0`.
8. Rule citations keep clause numbers unchanged (`§XI`, `§XIII`, `§6.5.4.3`…).
9. Game IDs like `1880-046` and map coordinates like `L14` are kept verbatim.
10. In the 13 log-trap rows, keep the *shape* of the log examples; the anonymised handles there
    (`Player20`, `Player23`, `Player22`, `Player7`, `Player19`) are already final.
