## 一、版式规范（`_tools/ppt_1846_kit.py`）

| 项 | 值 |
|:--|:--|
| 画布 | 13.333 × 7.5 英寸（16:9）；页边距 0.62 英寸 |
| 底板 / 内容面 | `#F9F9F7` / `#FFFFFF` |
| 主字 / 次字 / 弱化 | `#0B0B0B` / `#52514E` / `#898781` |
| 网格 / 分隔 | `#E1E0D9` / `#C3C2B7` |
| 主强调 | `#2A78D6`（蓝）；顺序槽：橙 `#EB6834`、青 `#1BAF7A`、黄 `#EDA100`、品红 `#E87BA4`… |
| 状态色 | good `#0CA30C`／warn `#FAB219`／critical `#D03B3B`（**只用于状态，不当作第 N 条系列**） |
| 字体 | Microsoft YaHei（**必须同时写 latin 与 `a:ea`**，否则中文回退成宋体） |
| 标题 / 正文 / 表格 | 26pt / 13–14.5pt / 11–12pt |

**内容区纵向预算：1.62 → 6.92 英寸（5.30 英寸）**，页脚在 7.03。

## 二、六条硬规矩

1. **数据必须从主报告逐条转录，不能凭记忆**——PPT 里每个数字都要能在 .md 里指到。
2. **不做双轴图**（两个 y 标度）。两种量纲 → 两张图，或同一图里换用「值+标签」表达。
3. **单一色相强调**：要突出某一条时，用深色 vs 浅色（如 `#2A78D6` vs `#B8D3F2`），不要给一条数据换一个色相。
4. **表格里的颜色必须带符号**（`↑最高` `↓最差`），不能只靠颜色表意。
5. **正文不能只剩表格**——每张表后配解读与案例（与主报告同要求）。
6. **零动画、零转场**。汇报类 PPT。

## 三、页型（照 1846 抄即可）

| 页型 | 用途 | 组件 |
|:--|:--|:--|
| 封面 / 封底 | 标题 + 数据基础 + **署名与致谢** | 无页眉 |
| 章节页 | 大号章节号 + 标题 + 一句导语 | `section()` |
| 要点页 | 2–4 条「标题＋正文」 | `blocks()` |
| 数据页 | 3–4 张大数字卡 | `tiles()` |
| 表格页 | 表头深底白字，隔行浅底 | `table()` |
| 图表页 | matplotlib 出图嵌入 | `pic()` |
| 结论页 | 左侧色条 + 一句话 | `callout()` |

## 四、版式自检（**必做**）

`ppt_1846_kit` 内置检查：`footer()` 会汇总本页所有组件记录的上下边界，报出

- **溢出**：组件底边超过 6.92 英寸；
- **重叠**：同页两个组件的纵向区间相交；
- **文字超框**：按字符宽度（CJK 记 1、拉丁记 0.55）估算行数，判断填充色块高度是否够装。

```python
import sys; sys.path.insert(0, "D:/兵棋/18xx/_tools")
import build_1846_ppt as B; B.main()
import ppt_1846_kit as K
print(K._OVERFLOW)     # 必须为空列表
```

**⚠ 一定要再用 PowerPoint 导 PNG 亲眼看**（`pptx_to_png.py`）。自动检查只能抓几何问题，抓不到配色、图例遮挡、标签碰撞这类问题——1846 第一版就是这么发现「图例压住数据标签」的。

> **踩过的坑**：改 `blocks()` 的行数估算时，曾把正文列表替换成了等高占位空串，结果**所有正文都不渲染**、而自动检查全绿。**凡是动过渲染函数，必须重新导出 PNG 抽查若干页。**

## 五、给新作品做 PPT

1. 复制 `_tools/ppt_1846_kit.py`（版式工具与作品无关，直接用）；
2. 新建 `_tools/build_<作品>_ppt.py`，照 1846 的页序：**封面 → 目录 → 每章章节页 → 各章 1–4 页 → 速查 → 局限 → 封底**；
3. 图表函数照抄改数据即可（`clean_axes()` 已统一网格与轴样式）；
4. 每章至少一页「机制」+ 一页「数据/案例」；
5. 篇幅参考：**1846 的 21 个章节 = 55 页**（平均每章 2.6 页）；**1880 的 11 个章节 = 48 页**（平均每章 4.4 页——章节少但每章更厚，拍卖与公司两章各 7 页）。别把整份报告塞进一页。
6. **版本号与报告同步**：封面页与封底页的 `vX.Y` 必须等于主报告版本；报告升版后 PPT 必须重建（1880 曾出现报告 v1.3、PPT 仍写 v1.2）。
