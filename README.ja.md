## 2. 手法（要約）

| 段階 | 内容 | ゲート |
|:--|:--|:--|
| **S0 ルール確定** | 本作の英語原ルールを条文ごとに読み、分析済み作品との9つの機構差を洗い出す | ルールの誤り = 全滅 |
| **S1 取り込み** | 単局／合本／局ヘッダなしの3種のソースを分割；**内容 sha1 で重複排除**；正規番号 + `_mapping.csv` | 重複排除後のサンプルが一意 |
| **S2 解析** | 作品専用の記帳ステートマシンを書き、プレイヤーごとに現金／持株／純資産を再構築する | **末尾で公式精算とプレイヤーごとに照合** |
| **S3 抽出** | parse ステートマシンを再利用し、傍観のみで改変せず、`_full.json` を一括出力する | 照合率をレポート冒頭に記載 |
| **S4 集計** | 14種の専用スクリプト（初手列車の組み合わせ、列車ラッシュ、金庫、手番順、株価叩き、レーティング…） | すべての数字がスクリプト出力まで辿れる |
| **S5 レポート** | 固定骨格：データと照合→プレイヤー層→機構と行動→早見→手法と限界 | 納品前チェックリスト |

**いくつかの固い基準**：

- 前二制の rank rating：1位 +2、2位 +1、3位以降 −(rank−2)；「前二 vs 前二以外」の比較ペアだけを作る；
- 正規化順位 =(順位−1)/(人数−1)、**平均順位は人数をまたいで比較しない**；
- 前二率は ≥4 人局でのみ集計する；n<20 のセルは参考値とする；
- ランダム属性は局をまたいで使い回さない（1862 の営業許可は毎局結び直されるため、「会社 × 許可」に分解する）；
- 相関 ≠ 因果。因果の疑いは1件ずつ別に挙げる。

完全な流れと18の鉄則は [skill](<skills/18xx-analysis/SKILL.md>) を参照。

## 3. プレイヤーの匿名化

これは**すべての成果物**に課す必須要件である（2026-09-24 以降）：

- **TOP 組は実名を残す**（公開対局の高レベルプレイヤーで、追跡可能性を保つ）；
- **MID / BOT 組は一律「PlayerX」と記す**（英語版では `PlayerX`）。番号は強さスコアの降順で振り、MID の区間を先、BOT の区間を後に置く；
- 層の境界は作品ごとに独立（1846 は印刷リスト順、1880 は BT≥2.0、1830 は BT≥1700/≤1420、1862 は BT≥1700）；
- 納品前に `anonymize_18xx.py --check` を実行し、PPT は `build_*_ppt.py` で再生成する（XML を手で編集しない）。

## 4. データの出所と謝辞

**対局データはすべて [18xx.games](https://18xx.games/) とそこに集うプレイヤーたちによるもの**である。彼らが無償で公開したプレイ記録が、この分析を成り立たせている。公開ログがなければ、本プロジェクトには1局たりともデータがない。

- レポートの冒頭と末尾に謝辞を置く；
- 対局ログの原文と元の解析スクリプトは**本リポジトリには置かない**（容量とデータ境界のため）。レポート中の数字にはすべてスクリプトと口径を添えてあり、確認が必要なら Issue で連絡してほしい。

## 5. 著作権と利用

- **分析テキスト、図表、PPT**：Pig9013 のオリジナル。**転載時は著者と出典を明記し、商用利用は禁止**；
- **対局データ**：著作権は 18xx.games と各プレイヤーに帰属する。本リポジトリは統計的な引用のみを行い、ログ全文は転載しない；
- ルールの引用は英語原ルールを正とし、中国語訳は対照用にすぎない。誤訳を見つけた場合はレポートで指摘する。
